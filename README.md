# SCS Flood Hydrograph

A lightweight, portable Python tool for SCS flood hydrograph calculation (Lumped & ModClark methods).

## Download

Go to the [Releases page](https://github.com/bahramchoubin/SCS-Flood-Hydrograph/releases) and download the latest ZIP.

## How to use

1. Download and extract the ZIP file.
2. Run `SCS_Hydrograph.exe` (no installation required).
3. Load your rainfall TXT file, CN raster, and flow length raster.
4. Click "Compute Hydrograph".
